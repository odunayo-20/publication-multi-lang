# Publication

A multi-language (English, Croatian) publication site. Next.js 16 + Payload 3 + Postgres, deployed on Vercel.

Plan and build procedure: [Docs/PLAN.md](Docs/PLAN.md), [Docs/BUILD-PROCEDURE.md](Docs/BUILD-PROCEDURE.md).

## Requirements

- Node 24 (see `.nvmrc`)
- A Postgres database (a free [Neon](https://neon.tech) project works for local dev too)

## Setup

```bash
npm install
cp .env.example .env     # then fill in values
npm run generate:types
npm run dev
```

- Site: http://localhost:3000 (redirects to `/en`)
- Admin: http://localhost:3000/admin (the first user you register becomes admin)

## Environment variables

| Name                     | Purpose                                                                         |
| ------------------------ | ------------------------------------------------------------------------------- |
| `DATABASE_URL`           | Postgres connection string                                                      |
| `PAYLOAD_SECRET`         | Long random string for signing sessions                                         |
| `NEXT_PUBLIC_SERVER_URL` | Public base URL, no trailing slash                                              |
| `BLOB_READ_WRITE_TOKEN`  | Vercel Blob token (production media). Empty locally, so uploads go to `./media` |

## Scripts

| Script                            | What it does                                                 |
| --------------------------------- | ------------------------------------------------------------ |
| `npm run dev`                     | Start dev server                                             |
| `npm run build` / `start`         | Production build and serve                                   |
| `npm run lint`                    | ESLint                                                       |
| `npm run format` / `format:check` | Prettier                                                     |
| `npm run typecheck`               | TypeScript check                                             |
| `npm run generate:types`          | Regenerate `src/payload-types.ts` after changing collections |

## Layout

```
src/
  access/        access-control helpers
  collections/   Payload collections (Articles, Authors, Tags, Media, Users)
  fields/        reusable field definitions
  i18n/          locale config (and UI messages)
  app/(frontend)/[locale]/   public site
  app/(payload)/             admin and API (generated by Payload, rarely edited)
  payload.config.ts
Docs/            plan, build procedure, module specs
```
