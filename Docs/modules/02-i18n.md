# 02: Internationalization (English + Croatian)

**Goal:** Every page, URL and piece of content works in `en` and `hr`, and adding a third language is a config change.
**Depends on:** 01
**Status:** partial (locale routing and Payload localization configured)

## Scope

Locale routing, UI string dictionary, localized content fallback, language switcher, `hreflang`, locale detection, localized formatting.

## Out of scope

Machine translation, right-to-left layouts.

## Tasks

- [x] `src/i18n/config.ts` as the single source of truth for locales
- [x] `[locale]` route segment, invalid locale returns 404
- [x] Payload `localization` with fallback; admin UI available in en and hr
- [ ] UI dictionary (`src/i18n/messages/{en,hr}.json`) and a typed `t()` helper; no hard-coded UI strings in components
- [ ] Locale detection at `/`: cookie, then `Accept-Language`, then default; implemented in `proxy.ts`; remembers the choice
- [ ] Language switcher keeps the user on the equivalent page (same article, other language), not the homepage
- [ ] If an article has no translation: show fallback with a visible "Not available in Croatian" notice, plus `noindex` on the fallback version
- [ ] `hreflang` alternates and `x-default` in every page's metadata
- [ ] Locale-aware dates, numbers, and Croatian plural rules (1 članak, 2 članka, 5 članaka)
- [ ] Editor UX: in admin, show which locales of an article are complete

## Acceptance criteria

- `/` redirects to the user's preferred language and never loops.
- Switching language on an article page lands on the same article in the other language, or the notice.
- Search engines get correct `hreflang` pairs.
- No English text appears on a Croatian page except intentional fallback content.

## Security

- Locale comes from an allowlist only; never reflected unvalidated into URLs, headers or queries.
- Cookie: `SameSite=Lax`, `Secure` in production, no personal data.

## Tests

- Unit: locale guard, plural helper, message key parity (en and hr have identical keys; CI fails otherwise).
- E2E: detection, switcher, fallback notice, `hreflang` output.

## Decisions

- Launch languages: English (default), Croatian.
